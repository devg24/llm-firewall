- (decision) Use 1-way redaction: ensures no sensitive data reaches external APIs.
- (decision) Use pure Rust and HuggingFace Candle: achieves zero-dependency, infinite horizontal scaling, and sub-10ms latency.
- (decision) Extract API keys from Authorization headers: avoids centralized key management.
- (decision) Use hardcoded regexes: provides maximum speed and simplicity for Tier 1 redaction.
- (decision) Stateless operation: allows proxy to retain no memory of requests for scaling.
- (decision) Success Metrics: Best effort recall, flexible <25ms latency overhead, no specific RPS target for MVP
- (decision) Non-Goals: Stateful 2-way redaction and dynamic rule configuration are strict non-goals. Downstream app handles redacted tokens.
- (decision) Regex bounds: Target strictly formatted SSNs and Credit/Debit cards to minimize false positives.
- (decision) Regex scope: Include emails, phone numbers, and IP addresses in Tier 1 redaction to ensure strict PII compliance.
- (event) PRD finalized
- (decision) Scope: OpenAI API format only for MVP. Anthropic and Gemini support pushed to a stretch goal.
