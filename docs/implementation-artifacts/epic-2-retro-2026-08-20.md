## ✅ What Went Well & Breakthroughs
1. **Local CA & macOS Trust Store Automation (`ca.rs`):**
   - Implemented self-signed root CA generation with constrained basic constraints (`rcgen::BasicConstraints::Constrained(0)`).
   - Wrapped OS-level execution (`security add-trusted-cert` / `remove-trusted-cert`) behind a mockable `CommandRunner` trait, enabling 100% unit test coverage without modifying the host machine's system keychain during CI.
2. **Comment-Preserving Config Patcher (`patcher.rs`):**
   - Avoided naive `serde_json` serialization that strips user comments (`//`) and custom formatting from `settings.json`.
   - Engineered an `OrchestratorGuard` with Rust `Drop` trait semantics to guarantee full rollback of IDE configurations upon `Ctrl+C` or unexpected crashes.
3. **High-Performance Scare Report Scanner (`scanner.rs`):**
   - Integrated `ignore::WalkBuilder` for millisecond-scale `.gitignore`-aware file traversal.
   - Enforced defensive security bounds (5MB max file size, 500ms timeout per file) and offloaded CPU-intensive regex matching to `tokio::task::spawn_blocking` to protect Tokio async workers.
4. **Follow-Through on Epic 1 Action Items:**
   - Evaluated and integrated `unicode-normalization` (NFC) and zero-width character stripping into `guardian-core::redact` to eliminate evasion vectors.

## ⚠️ Challenges & Discoveries from Code Review
1. **Private Key Permissions:**
   - *Discovery:* CA private keys were initially written with default OS file masks.
   - *Resolution:* Hardened in code review with Unix `0o600` permissions.
2. **Running IDE Caching:**
   - *Discovery:* IDEs (Cursor/VSCode) only parse proxy settings at boot time; runtime patching without restart notices causes confusion.
   - *Resolution:* Added cross-platform process inspection (`pgrep` / `tasklist`) to warn developers when a running instance needs a restart.
