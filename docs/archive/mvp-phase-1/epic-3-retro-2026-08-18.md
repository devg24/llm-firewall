## ✅ What Went Well & Technical Strengths
1. **Zero-Network Architecture**: Relying entirely on locally hosted, quantized Hugging Face models guarantees enterprise data compliance.
2. **Safe Concurrency**: Bounding async network requests from blocking CPU math was handled gracefully, preventing the proxy from collapsing under load.
3. **Complex Offset Mapping**: Bridging subword tokens (`B-PER`, `I-PER`) seamlessly with rigid Tier 1 Regex byte offsets allowed for robust, overlap-free redactions.

---

## ⚠️ Challenges & Friction Points
1. **Thread Contention**: Initial naive implementations of Semaphores leaked permits and caused systemic lockups. Required refactoring into closures.
2. **JSON Tree Mutation Complexity**: Async boundaries made traversing the untyped JSON tree difficult, especially while adhering to the single-pass sequential map constraint.
3. **ML Chunking Nuances**: Long prompts broke the strict 512-token BERT limit. Creating a sliding-window chunking strategy that preserved subword entities was technically dense.
