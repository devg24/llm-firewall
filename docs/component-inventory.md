# Component Inventory

This is a backend Rust project (LLM Firewall) operating as an HTTP proxy.

## UI Components
There are no frontend UI components, widgets, or view templates in this repository.

## Internal Components
- **Proxy Handlers**: Implemented via Axum handlers in `guardian-proxy`.
- **Core Engine**: Detection and Redaction components in `guardian-core`.
- **CLI Utilities**: Command-line stats and reporters in `guardian-cli`.
